### Задание 1
Вычисление синуса угла, заданного в градусах.

### Задание 2
Вычисление математической функции:

t = 0.3

a = lg|tx + t²|

b = xt² + √x

y = ln(a² / (a + b))

Контрольный пример:
- x = 5.2
- y ≈ -4.14

### Задание 3
Проверка логических условий:

1. Только одно из чисел A и B является чётным.
2. Каждое из чисел A, B и C кратно трём.

A, B и C — целые части чисел a, b и y соответственно.
